Preview a Documentation Site

Serve a local folder of HTML documentation and check it before publishing.

TopOverviewStepsReference

Overview

This example explains a small local preview workflow. You need Python 3 and a folder containing an index.html file with its assets. The server is for local review, and binds only to your computer.

Keep assets together

Relative stylesheet and image URLs must resolve from each HTML file. Serve the complete documentation folder.

Steps

  1. Open a terminal in your documentation folder.
  2. Run the preview server:
    python3 -m http.server 8000 --bind 127.0.0.1
  3. Open http://localhost:8000/ and check the page, navigation, and styling.
  4. Press Ctrl+C in the terminal when your review is complete.
If port 8000 is already in use

Use 8001 in both the server command and browser address. Confirm you are viewing the intended folder before reviewing.

Reference

Success
The index and its linked assets load from the preview server.
Review scope
Check wide and narrow layouts, use Tab to reach links, and activate the skip link and disclosure.
